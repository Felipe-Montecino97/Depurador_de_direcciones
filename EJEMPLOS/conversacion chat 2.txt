Pensado durante 44s

Sí. Para sacarlo desde la BCN/SIIT, la vía más robusta es usar los mapas vectoriales de la BCN: ahí están los ZIP de División comunal y División regional en shapefile. La BCN indica que esas capas son reutilizables citando la fuente, pero también advierte que son referenciales y no para precisión geodésica.

La BCN también tiene Reportes Comunales 2025, que sirven para validar datos por comuna, región y provincia.

Opción recomendada: extraer catálogo desde shapefiles BCN

Este script te deja un CSV con comunas y región. Si el shapefile comunal ya trae la región como atributo, la usa; si no, hace cruce espacial con la capa regional.

# pip install geopandas pandas pyogrio requests

import requests
import zipfile
from pathlib import Path
import geopandas as gpd
import pandas as pd

OUT = Path("bcn_chile")
OUT.mkdir(exist_ok=True)

urls = {
    "comunas": "https://www.bcn.cl/obtienearchivo?id=repositorio/10221/10396/2/Comunas.zip",
    "regiones": "https://www.bcn.cl/obtienearchivo?id=repositorio/10221/10398/2/Regiones.zip",
}

def download_zip(name, url):
    zip_path = OUT / f"{name}.zip"
    r = requests.get(url, timeout=60)
    r.raise_for_status()
    zip_path.write_bytes(r.content)

    extract_dir = OUT / name
    extract_dir.mkdir(exist_ok=True)
    with zipfile.ZipFile(zip_path) as z:
        z.extractall(extract_dir)
    return extract_dir

def first_shp(folder):
    files = list(folder.rglob("*.shp"))
    if not files:
        raise FileNotFoundError(f"No encontré .shp en {folder}")
    return files[0]

comunas_dir = download_zip("comunas", urls["comunas"])
regiones_dir = download_zip("regiones", urls["regiones"])

comunas = gpd.read_file(first_shp(comunas_dir))
regiones = gpd.read_file(first_shp(regiones_dir))

print("Columnas comunas:", list(comunas.columns))
print("Columnas regiones:", list(regiones.columns))

# Ajusta estos nombres si al imprimir columnas aparecen distintos
def pick_col(df, candidates):
    cols = {c.lower(): c for c in df.columns}
    for cand in candidates:
        if cand.lower() in cols:
            return cols[cand.lower()]
    return None

comuna_col = pick_col(comunas, ["COMUNA", "NOM_COMUNA", "NOMBRE", "NOM_COM"])
region_col_comunas = pick_col(comunas, ["REGION", "NOM_REGION", "NOMBRE_REG", "REGIÓN"])
region_col_regiones = pick_col(regiones, ["REGION", "NOM_REGION", "NOMBRE", "REGIÓN"])

if comuna_col is None:
    raise ValueError("No encontré columna de nombre de comuna. Revisa el print de columnas.")

if region_col_comunas:
    catalogo = comunas[[comuna_col, region_col_comunas]].copy()
    catalogo.columns = ["comuna", "region"]
else:
    if region_col_regiones is None:
        raise ValueError("No encontré columna de nombre de región. Revisa el print de columnas.")

    # Cruce espacial: comuna dentro/intersecta región
    comunas = comunas.to_crs(regiones.crs)
    comunas_centroides = comunas.copy()
    comunas_centroides["geometry"] = comunas_centroides.geometry.representative_point()

    joined = gpd.sjoin(
        comunas_centroides[[comuna_col, "geometry"]],
        regiones[[region_col_regiones, "geometry"]],
        how="left",
        predicate="within"
    )

    catalogo = joined[[comuna_col, region_col_regiones]].copy()
    catalogo.columns = ["comuna", "region"]

catalogo = (
    catalogo
    .drop_duplicates()
    .sort_values(["region", "comuna"])
    .reset_index(drop=True)
)

catalogo.to_csv("catalogo_comunas_regiones_bcn.csv", index=False, encoding="utf-8-sig")

print(catalogo.head())
print(f"Total comunas: {len(catalogo)}")

Pensado durante unos segundos

Perfecto, para un depurador de direcciones, la recomendación tiene sentido, pero conviene separar dos cosas:

BCN sirve muy bien para el maestro territorial oficial/base: región, provincia, comuna y geometría/límites.
BCN no siempre es suficiente para normalizar direcciones completas, porque una dirección tiene otros componentes: calle, numeración, localidad, villa/población, código postal, coordenadas, etc.

La BCN/SIIT publica mapas vectoriales de la división político-administrativa y permite reutilizarlos citando como fuente a la Biblioteca del Congreso Nacional. También indica que la actualización depende de la disponibilidad de nuevas versiones, por lo que no debe tratarse como una API transaccional siempre actualizada.

Para tu caso, yo construiría un archivo maestro mínimo así:

codigo_region,nombre_region,codigo_provincia,nombre_provincia,codigo_comuna,nombre_comuna,nombre_comuna_normalizado,fuente,fecha_extraccion

Mi recomendación práctica

Usa la BCN como fuente base para región/provincia/comuna, pero arma tu maestro en 3 capas:

1. Maestro oficial BCN

Tabla limpia con comunas, provincias y regiones. Esta es la referencia canónica.

2. Tabla de normalización

Sirve para comparar texto ingresado por usuarios:

valor_original,valor_normalizado,tipo
Ñuñoa,NUNOA,comuna
Nunoa,NUNOA,alias_comuna
Región Metropolitana,REGION METROPOLITANA DE SANTIAGO,alias_region
RM,REGION METROPOLITANA DE SANTIAGO,alias_region

3. Tabla de reglas de depuración

Por ejemplo:

campo,regla
comuna,quitar_tildes
comuna,mayusculas
comuna,quitar_puntos
region,reemplazar_RM_por_REGION_METROPOLITANA_DE_SANTIAGO
direccion,reemplazar_AVDA_por_AVENIDA
direccion,reemplazar_AV_POR_AVENIDA
direccion,normalizar_espacios
Flujo sugerido para depurar direcciones

Cuando recibas una dirección como:

Av. Providencia 1234, Providencia, RM

El depurador debería:

Normalizar texto: mayúsculas, sin tildes, sin dobles espacios.
Separar componentes: calle, número, comuna, región.
Buscar comuna contra el maestro BCN.
Validar que la comuna pertenezca a la región indicada.
Corregir alias: RM → Región Metropolitana de Santiago.
Devolver una salida estructurada.

Ejemplo de salida:

{
  "direccion_original": "Av. Providencia 1234, Providencia, RM",
  "calle_normalizada": "AVENIDA PROVIDENCIA",
  "numero": "1234",
  "comuna": "Providencia",
  "region": "Región Metropolitana de Santiago",
  "estado_validacion": "OK",
  "fuente_territorial": "BCN-SIIT"
}
Lo importante

No usaría el maestro BCN como “depurador completo”, sino como catálogo territorial maestro. Para direcciones, tu archivo maestro debería partir con BCN, pero después enriquecerlo con alias, reglas de escritura y equivalencias comunes.

La BCN es buena para responder preguntas como:

“¿Existe esta comuna?”
“¿A qué región pertenece esta comuna?”
“¿Esta comuna corresponde a esta provincia/región?”

Pero no necesariamente para:

“¿Existe esta calle?”
“¿El número 1234 está dentro de la comuna?”
“¿Cuál es el código postal?”
“¿Cuál es la coordenada exacta?”

Para eso necesitarías complementar con otra fuente, como Correos de Chile, IDE Chile, mapas oficiales, catastro interno o servicios de geocodificación.
